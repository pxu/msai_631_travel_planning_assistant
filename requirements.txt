# Runtime dependencies.
#
# Upper bounds are deliberate. This project's behaviour is version-sensitive
# in two places that have already bitten it: `HuggingFacePipeline` only reads
# invoke-time generation overrides from a nested `pipeline_kwargs` dict, and
# `from_model_id(device=...)` accepts a legacy CUDA index rather than a
# device string (see travel_assistant/llm.py). An unpinned major bump would
# change either silently. Bounds are set at the next major so patch and
# minor upgrades still flow in.
#
# `torch` is intentionally left with only a lower bound: Colab ships its own
# CUDA-matched build, and pinning it there causes a reinstall that breaks GPU
# support. Versions verified against this set are recorded in the README.
